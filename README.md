# 📩 Discord Temp Mail Bot

A clean and simple Discord bot that lets users generate temporary email addresses, check their inbox, view messages, and delete them — all through slash commands.

Powered by the awesome free service: [email.vwh.sh](https://email.vwh.sh) 💙

## ✨ Features

- `/newemail` – Get a new random temporary email (every time).
- `/myemail` – View all your generated emails.
- `/inbox` – View the inbox of your **latest email**.
- `/view <message_id>` – View a specific email message by ID.
- `/delete <message_id>` – Delete a message by ID.
